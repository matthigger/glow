🧠 GLOW Viewer

General Linear models Optimized with Ward's method — hierarchical, region-based effect discovery in imaging data.

The interactive viewer is hosted at glow-viewer.web.app. It needs a live Python process (Dash), which a static page cannot host, so this Space points at it rather than serving it.

Open the interactive demo →

The demo scales to zero between visitors, so the first load after a quiet spell takes a few seconds to wake up.

What is in it

One fitted GLOW analysis per link, each a cell of the benchmark the paper reports, grouped by the axis it sits on: effect strength, the null case, feature count, effect extent, Ward projection, selection rule, and analysis volume. Each one opens a region scatter, a volume overlay, a per-region regression, and — where the draws were kept — a permutation histogram.
